# Jargon Buster

Plain-English explanations of the technical words in this kit.

**Agent**
An AI system that does tasks for you. It can use tools, read data, and take actions, not only answer questions.

**Agent skill**
A file of instructions that an AI agent can load to do one type of task. The skills in these kits use the open [Agent Skills](https://agentskills.io) format.

**Attestation**
A signed statement from a trusted source, for example a hardware chip, that a fact is true. For example: "this program ran on this machine, in this region."

**Audit trail**
A record of what an agent did, and when. A good audit trail cannot be changed later, so you can use it as proof.

**Authority grant**
A record of the permissions that a person gives to an agent for one task. It shows what the agent can do, for how long, and who gave the permission.

**Behavioral rules file**
A file that lists the rules of an agent: what it must do, what it must never do, and when it must stop and ask a person. Some agents call this file `SOUL.md`.

**Conformance level**
A level that shows how many of the rules in a specification an agent meets. A higher level means that the agent meets more of the rules.

**Containment**
The first step when an agent goes wrong: stop the problem from becoming larger. For example, stop the agent, or remove its access to a tool.

**Control**
A rule, a check, or a step that stops a harm or makes a risk smaller. For example, a person must confirm a payment before the agent sends it.

**Data residency**
The country or region where data is kept and processed.

**Delegated authority**
Permission that one person gives to an agent so that the agent can act for that person. The permission must have limits, and the person must be able to stop it.

**Evidence**
A file, a log, or a test result that shows that a control works. The memory of an agent is not evidence.

**Governance**
The rules, the checks, and the responsibilities that make sure that an agent does what it must do, and nothing more.

**Harm**
A bad effect on a person. The person can be a user of the agent or a different person that the agent acts on.

**Identity binding**
The proof that connects the name of an agent to the person or company that controls it.

**Jurisdiction**
The law that applies to data or to a company in a given place. A company in one country can have to obey the law of that country for data that it keeps in a different country.

**Playbook**
A short, written plan for one type of incident. It tells you the steps to do, in order, and who does each step.

**Receipt**
A signed record of one action of an agent. The receipts link in a chain, so you can see if somebody changed or removed a record.

**Risk tier**
A level of risk, from low to high. A higher tier needs more controls.

**Sovereignty**
Control over where your data goes and which laws apply to it. For example, data that goes to a different country can come under the laws of that country.
